# Phase 5 learning tools

JavaLab now includes fifteen starter examples that compile against its real supported subset: output, variables, arithmetic, Scanner input, conditionals, switch, loops, arrays, methods, objects, constructors, String operations, inheritance, and exception handling.

Use **Examples** to load one. Loading an example replaces the current editor source, so save work first when the unsaved marker is visible.

## Local projects

**Save** stores the current project locally in the current browser only. **Open** lists saved projects and lets you open, rename, or delete them. The same dialog can import a `.java` source file, export the source, and download the generated JavaScript after a successful Check.

Local projects do not synchronize across browsers, devices, private sessions, or cleared browser data. Storage errors are reported in the console instead of being presented as a successful save.

## Inspecting and learning

Use **Check** to run parsing and supported semantic checks, view diagnostics with source locations, and populate the JavaScript and AST inspector tabs. Use **Run** only after a successful Check; it runs the generated translation, never a hard-coded sample result.

The Help dialog explains input, projects, examples, inspection, and the learning-subset boundary. See `phase-4-supported-subset.md` for the exact compiler/runtime scope.
