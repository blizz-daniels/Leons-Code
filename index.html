JavaLab learning guide

Write Java in the editor, select Check to inspect diagnostics, AST data, and the generated JavaScript, then select Run to execute the documented subset in an isolated frame.

Use Examples for tested starter programs. Save projects locally in this browser, reopen them from Open, and use its Import, Export, and Download JavaScript tools when needed.

For Scanner examples, the program pauses at input; enter a token or line in Program input and select Send input. JavaLab is a learning subset, not a full JDK.

Supported language details are documented in docs/phase-4-supported-subset.md; execution limits and deployment guidance are in docs/phase-6-security-and-deployment.md.

Use Ctrl + S to save this browser session, Tab to indent, and Ctrl + F to find or replace text.
